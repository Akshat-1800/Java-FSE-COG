# Git Commands 

According to the instructions received in the **Week 6 Masterclass**, this repository contains the Git commands for **all 5 mandatory hands-on exercises**.

## Contents

* Git configuration and setup (including configuring Notepad++ as the default Git editor)
* Creating and initializing a Git repository
* Adding, staging, and committing files (including use of `.gitignore`)
* Branch creation, merging, and resolving merge conflicts
* Pulling from and pushing to a remote repository

These commands have been organized as part of the mandatory hands-on exercises and are intended for learning and reference purposes.
